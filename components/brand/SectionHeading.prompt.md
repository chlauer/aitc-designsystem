Eyebrow + condensed uppercase title + lead. Every content section starts with one.

```jsx
<SectionHeading eyebrow="Das Netzwerk" title="Expertise, die zusammenarbeitet"
  lead="Wir bringen Strategie, Daten und Befähigung an einen Tisch." />
```

`size="lg"` for hero-adjacent openers, `sm` inside cards. `align="center"` only on full-bleed sections.
