Primary action control — the only element allowed to carry brand fill on light surfaces.

```jsx
<Button variant="primary" iconEnd={<ArrowRight />}>Gespräch vereinbaren</Button>
<Button variant="secondary">Programm ansehen</Button>
<Button variant="ghost" size="sm">Alle Themenfelder</Button>
```

Variants: `primary` (teal fill), `secondary` (navy hairline outline), `ghost` (teal text), `inverse` (white on teal/navy sections), `danger`. Sizes 34 / 44 / 54px. Pass `href` to render an anchor. Radius stays 3px — never rounded pills.
